# Ria Choi Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, and GSAP.

## Live site

https://ria-choi-portfolio.vercel.app/

## Development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

Vercel uses `Frontend` as the root directory and `dist` as the output directory. Client-side routes are served through `vercel.json`. Existing project APIs remain on their current backend hosts.
